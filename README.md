# Dog Register – Java

Project Description:

A Java-based command-line application for managing dogs and their owners. The program allows users to register, update, search, sort and remove dogs and owners through a text-based menu.

Features:

Register and remove dogs and owners

Assign dogs to owners and remove ownership

List registered dogs and owners

Increase a dog's age

Sort dogs by name and tail length

Validate user input

Technologies & Concepts:

Java

Object-Oriented Programming (OOP)

Classes, objects and encapsulation

ArrayLists and arrays

Collections and data management

Interfaces and comparators

Sorting algorithms

Input validation
